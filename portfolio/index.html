Sobre mim

Do problema real ao site no ar

Comecei no desenvolvimento web resolvendo um problema concreto: um negócio que precisava de presença digital própria, com serviços, preços e agendamento organizados em um único lugar. Desse desafio nasceu o Victor Barber, site institucional publicado e em uso.

Gosto de trabalhar próximo do fundamento — HTML semântico, CSS bem organizado e JavaScript sem frameworks — para entender de verdade o que acontece em cada camada da página.

Cada projeto é também um exercício de produto: entender o problema, decidir a identidade visual, escrever o conteúdo e publicar algo que funcione bem no celular de quem vai usar.

Foco atual

Desenvolvimento front-end e sites institucionais para pequenos negócios.

Como trabalho

Código sem frameworks, versionado com Git e publicado com deploy contínuo.

O que valorizo

Páginas leves, layout responsivo e chamadas para ação claras.
