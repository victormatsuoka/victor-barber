# Victor Barber

Site profissional desenvolvido para a marca Victor Barber, com foco em apresentar os serviços, fortalecer a presença digital e facilitar o contato com clientes.

## Funcionalidades

- Página inicial responsiva
- Apresentação dos serviços
- Galeria de trabalhos
- Botões de contato
- Experiência adaptada para celular
- Animações e transições visuais

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo do projeto

Criar uma experiência digital premium para uma barbearia brasileira no Japão, facilitando a apresentação dos serviços e o contato com potenciais clientes.

## Status

Projeto desenvolvido como solução de presença digital para uma barbearia brasileira no Japão e utilizado também para aplicar versionamento com Git e GitHub.
